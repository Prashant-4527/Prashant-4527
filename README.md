## 🔨 What I'm Building

### 📚 [Shiori RAG](https://github.com/Prashant-4527/shiori-rag) · In progress
A Japanese/English question-answering system over Japanese policy documents. I'm currently working through document extraction, normalization, Japanese-aware chunking, and retrieval evaluation. The target is to answer from evidence, cite source pages, and abstain when the documents don't support an answer.

### 🛍️ [Furima Copilot](https://github.com/Prashant-4527/furima-copilot) · Early stage
A local-first assistant concept for turning item photos and seller-confirmed facts into editable Japanese listing drafts. The design emphasizes grounded claims, structured output validation, privacy, and seller review. The end-to-end workflow is not implemented yet.

## 🚀 Selected Projects

### 🧠 [Mercari Price Prediction System](https://github.com/Prashant-4527/mercari-price-prediction-system) · [Live demo](https://mercari-price-prediction-system-ct2v9yu2n6dxz6rlu8ncvu.streamlit.app/)
An end-to-end marketplace ML pipeline using text and structured features, leak-safe feature engineering, cross-validated model comparison, and a tested serving layer. The project reports **RMSLE 0.5214** on its held-out validation set and provides empirical residual-quantile price ranges alongside point predictions.

`Python` `scikit-learn` `TF-IDF` `FastAPI` `Streamlit` `Docker`

### 🇯🇵 [Japan Trade Intelligence](https://github.com/Prashant-4527/japan-trade-intelligence)
Policy-oriented analysis of Japan's bilateral trade exposure using UN Comtrade data across six economies. Includes sector-level dependency analysis, concentration-risk measures, supply-disruption scenarios, and a forecast compared with actual government data.

`Python` `Pandas` `Data Analysis` `Risk Modeling` `Forecast Validation`

### 🗄️ [MercariDB Analytics](https://github.com/Prashant-4527/mercaridb-sql)
A MySQL analytics capstone built around 50K Mercari listings, covering schema design, business questions, data-quality checks, advanced SQL, and measured query optimization. The project documents a representative query improvement measured with `EXPLAIN ANALYZE`.

`MySQL` `CTEs` `Window Functions` `Indexes` `Query Optimization`
