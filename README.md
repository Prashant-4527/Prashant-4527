## Current Work

### [Shiori RAG](https://github.com/Prashant-4527/shiori-rag) — In progress

A Japanese/English question-answering system over policy documents. Current work focuses on document extraction, text normalization, Japanese-aware chunking, and retrieval evaluation. The intended system will provide source-page citations and indicate when the documents do not support an answer.

**Focus:** Python, document processing, NLP, retrieval, evaluation.

### [Furima Copilot](https://github.com/Prashant-4527/furima-copilot) — Early stage

A local-first assistant concept for turning item photos and seller-confirmed facts into editable Japanese marketplace listing drafts. The design prioritizes grounded claims, structured validation, privacy, and seller review. The end-to-end workflow is still under development.

**Focus:** Local inference, structured generation, validation, human-in-the-loop design.

## Selected Projects

### [Mercari Price Prediction System](https://github.com/Prashant-4527/mercari-price-prediction-system) · [Live demo](https://mercari-price-prediction-system-ct2v9yu2n6dxz6rlu8ncvu.streamlit.app/)

An end-to-end marketplace pricing pipeline built with text and structured features, leak-safe feature engineering, cross-validated model comparison, and a serving layer. The repository reports **RMSLE 0.5214** on its held-out validation set and provides empirical residual-quantile price ranges alongside point predictions.

`Python` · `scikit-learn` · `TF-IDF` · `FastAPI` · `Streamlit` · `Docker`

### [Japan Trade Intelligence](https://github.com/Prashant-4527/japan-trade-intelligence)

A policy-oriented analysis of Japan's bilateral trade exposure using UN Comtrade data across six economies. It examines sector-level dependencies, trade concentration, disruption scenarios, and a forecast validated against actual government data.

`Python` · `Pandas` · `Data Analysis` · `Risk Modeling` · `Forecast Validation`

### [MercariDB Analytics](https://github.com/Prashant-4527/mercaridb-sql)

A MySQL analytics project using 50,000 Mercari listings. Covers relational schema design, business-focused SQL analysis, data-quality checks, advanced queries, and measured query optimization with `EXPLAIN ANALYZE`.

`MySQL` · `CTEs` · `Window Functions` · `Indexes` · `Query Optimization`
