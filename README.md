## 🏆 Featured Work

### 🚀 [Mercari Price Prediction System](https://github.com/Prashant-4527/mercari-price-prediction-system)

End-to-end ML system for marketplace price suggestion using real Mercari listing data.

- Leak-safe feature engineering with text + structured metadata
- TF-IDF + categorical features + target encoding in a unified `sklearn` pipeline
- Cross-validated model comparison across Ridge, LightGBM, and XGBoost
- **RMSLE 0.5214** on held-out validation
- FastAPI + Streamlit serving
- Dockerized with automated GitHub Actions tests
- **14/14 tests passing**

`Python` `scikit-learn` `TF-IDF` `FastAPI` `Streamlit` `Docker` `GitHub Actions`

### 🛒 [MercariDB Analytics](https://github.com/Prashant-4527/mercaridb-sql)

SQL analytics capstone built on **50,000 real Mercari listings**.

- Normalized relational schema with foreign keys and data-quality rules
- Business analysis across pricing, brands, categories, shipping, and listing quality
- Window functions, CTEs, recursive CTEs, views, and stored procedures
- Transactions and exception handling
- `EXPLAIN ANALYZE`-based optimization
- Measured a representative query improvement from **~188 ms to ~0.8 ms** using a composite index

`MySQL 8.0` `SQL` `Database Design` `Query Optimization` `Analytics`

### ✈️ [Flight Delay Prediction](https://github.com/Prashant-4527/flight-delay-prediction)

End-to-end ML pipeline for predicting 15+ minute arrival delays across **5.8M US domestic flights**.

- Logistic Regression → Random Forest → XGBoost comparison
- Class imbalance handling with `scale_pos_weight`
- SHAP-based explainability
- FastAPI inference service
- Docker + GitHub Actions CI/CD
- Streamlit dashboard with live aviation context

`Python` `XGBoost` `SHAP` `FastAPI` `Docker` `Streamlit`
